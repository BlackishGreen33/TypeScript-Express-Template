# Security Policy

## Supported Versions

Security fixes target the latest published version of `create-typescript-express` and the current `main` branch.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through GitHub's private vulnerability reporting for this repository.

Do not open a public issue for vulnerabilities, leaked credentials, or exploit details. Include the affected version or commit, reproduction steps, impact, and any known workaround.

If the report is valid, a fix will be prepared privately and disclosed after users have a reasonable upgrade path.
